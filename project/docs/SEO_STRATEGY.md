# SEO strategy

Существующая SEO-база сайта сохраняется. Будущий контент создаётся только из подтверждённых opportunities, соответствует релевантному search intent, не дублирует существующие страницы и проходит approval до публикации. На FOUNDATION SEO-контент не генерируется и публичные услуги не меняются.
